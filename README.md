# Python Mini Project – Expense Tracker

A simple menu-driven Python project to track daily expenses.

## Features
- Add expense (name, amount, category)
- View all expenses
- Total spending calculation
- Category-wise summary
- Data saved in JSON file (persistent storage)

## How to Run
1. Install Python 3
2. Run: python main.py
